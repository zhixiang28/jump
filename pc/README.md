# 跳一跳 自动按压（电脑版）

电脑用 USB 线抓 Android 手机的截图，显示在电脑上用滑鼠画线（或自动判断），算出按多久，再用蓝牙叫 ESP32 让 servo 用触控笔按。
**不用相机、不用画边框**。ESP32 的程序和蓝牙协议都不用改。

```
Android 手机 ──USB(adb 截图)──▶ Windows 电脑 ──蓝牙 P<ms>──▶ ESP32 ──▶ servo + 触控笔 按手机
```

## 一次性设定

1. **安装 Python**：到 <https://www.python.org/downloads/> 下载安装。安装第一页一定要勾选 **Add python.exe to PATH**。
2. **下载 adb**：到 <https://developer.android.com/tools/releases/platform-tools> 下载 *SDK Platform-Tools for Windows*，解压后把 `platform-tools` 资料夹放到 `C:\platform-tools`（或放进这个 `pc` 资料夹里）。
3. **手机开 USB 调试**：
   - 设置 → 关于手机 → 连点「版本号」7 次，开启开发者选项
   - 设置 → 系统 → 开发者选项 → 打开「USB 调试」
   - 小米 / 红米还要打开「USB 调试（安全设置）」
4. **用 USB 线接上电脑**，手机跳出「允许 USB 调试吗？」时，勾「一律允许」再按允许。
5. **双击 `安装.bat`**，安装需要的 Python 套件（numpy、pillow、bleak）。

## 推荐：手机画面 + 滑鼠画线（`画线.bat`）

适合任何「跳一跳」类的游戏（方块每次长得不一样也没关系）。

1. 手机打开游戏，触控笔架好；**关掉手机网页上的蓝牙连接**。
2. 双击 **`画线.bat`**，左边会出现手机画面。
3. 按「连接蓝牙」。
4. 用滑鼠**从小人脚底拉到目标中心**，放开后按 **空白键**（或勾「画完自动按」，放开就按）。
5. 按完会自动等动画、重新截图，接着画下一条。
6. 跳完看结果按 **1 跳太远 / 2 刚好 / 3 跳太近**，k 会自动调整。

| 操作 | 作用 |
|---|---|
| 左键拖曳 | 画线（每次都是新的线） |
| 空白键 | 按 |
| R | 重新截图 |
| 右键 | 清除线 |
| 1 / 2 / 3 | 跳太远 / 刚好 / 跳太近 |

「只算沿跳跃方向的距离」会把线投影到 30° 方向（蓝色虚线），手画歪一点也没关系。

### 🧠 让它自己学

你每画一条线按一次，程序都会记下来（`pc\data\`），并学三件事：

1. **小人长什么样**：线的起点就是小人脚底，用来做模板，之后它自己找得到小人。
2. **跳跃角度**：取你最近画的线的中位数。
3. **k / b**：跳完按 1 / 2 / 3，有结果的满 8 笔（而且远近要有差别），就能按「套用拟合 k/b」。

你玩的时候，AI 会在画面上画**紫色虚线**（它的预测），跟你画的线比较。
面板会显示「AI vs 你」的中位误差；**8 跳以上、误差 ≤3%** 就会提示够准了，这时勾「AI 自动玩」让它自己跳，按 **Esc** 停止。
AI 看不懂画面时（找不到小人或目标）会自己停下来，你手动画那一跳就好，它会继续学。

### 🎲 故意不跳正中（AI 自动玩）

在「⚙ 设定」：
- **故意偏离机率 %**（预设 10）：大约这个比例的跳会故意不跳正中。设 0 = 每跳都瞄正中。
- **偏离幅度 0~0.7**（预设 0.6）：最多偏到「顶面中心 → 边缘」距离的几成（只往跳跃方向偏远或偏近），
  再扣掉按压误差，保证还在平台上。
- 小平台（顶面宽 < 屏宽 25%）一律瞄正中。
- 故意偏离的跳不会影响自动校准；落点误差图用黄框标示，统计也会扣掉故意偏离的量。

### 🧩 目标记忆

AI 找不到目标、或 AI 的终点跟你画的差很多时，你手动画的那一跳会被记下来
（你画的终点附近那块方块 + 中心位置，最多 20 种）。之后遇到同一种方块：
规则找不到目标就用记忆（相似度 ≥ 0.75）；规则找到的位置跟「你纠正过的那种方块」不同、
而且非常像（≥ 0.93）时相信记忆。用记忆判断时，紫色线旁边会写「AI（记忆）」。

### 🔧 调整了装置（换了按压角度等）

换了 servo 角度、触控笔位置之后，按一下「🔧 我调整了装置」：之前的落点资料不再拿来校准，
接下来几跳会快速重新校准（先修 b，资料够了再一起修 k）。
没按也没关系：连续 5 跳都偏同一边时，程序会自己判断装置可能变了并重新校准。
如果 k、b 已经学到不合理的值（k < 0.6 或 b > 450），开启时会自动重设。

### 🏁 目标分数（AI 自动玩）

在「⚙ 设定」填 **目标分数**（0 = 不限）。程序每张截图都会读画面上方的分数（学习区会显示），
AI 自动玩读到分数 ≥ 目标时，会**故意跳过头**结束这一局；差 12 分以内时，在大平台上故意不跳正中
（只拿 +1，不拿 Perfect 的额外分），比较不会一下子超过太多。
分数被手机通知挡住时会沿用上一次读到的分数，建议玩的时候开「勿扰模式」。

### 🎯 跳完自动量落点、自动校准（预设开启）

每跳完，程序会等画面停下来，量**小人脚底离新方块顶面中心偏了多少**（沿跳跃方向，+ 是跳过头、− 是不够远），
状态列会显示例如「落点：跳过头 12（+2.6%）」。这就是这一跳精确的结果，**不用再按 1/2/3**：

- 资料少时：每跳单独修一点 k。
- 量到 6 跳以上（远近有差别）：用「按了几 ms → 实际跳多远」做最小二乘法，直接算出 k 和 b。
- 跳完找不到小人（掉下去了）：AI 自动玩会自己停下来。

金币那种没有奶油色顶面的方块量不到落点，会跳过（这时也可以按 1/2/3）。
不想让它自动改 k/b，就取消勾选「跳完自动量落点、校准 k/b」。

## 全自动（只适用微信「跳一跳」原版画面）

### 每次使用

1. 手机打开「跳一跳」进到游戏画面，触控笔架好在屏幕上。
2. **关掉手机网页上的蓝牙连接**（ESP32 同时只能连一个装置）。
3. 双击 **`开始.bat`**。它会自动连 ESP32，然后每一跳显示算出来的 ms：

| 输入 | 作用 |
|---|---|
| Enter | 按这一跳 |
| `a` | 全自动连续跳（全自动中按任意键回到手动） |
| `+` / `-` | 上一跳跳太近 / 跳太远，调整 k（方向跟上次相反，幅度减半） |
| `=` | 上一跳刚好，缩小调整幅度 |
| 数字（如 `650`） | 用这个 ms 按 |
| `k 1.52` / `b 30` | 直接设定 k、b |
| `r` | 重新截图 |
| `q` | 离开 |

建议先用手动模式（每跳按 Enter）跳几次，用 `+` / `-` 把 k 调准，再按 `a` 全自动。

## 校准

按压时间 = 距离 × k + b，距离单位跟网页一样（手机屏幕宽 = 1000）。
预设 k = 1.5、b = 0，只是起点；servo 下压和抬起要时间，所以每台装置都要自己调。
设定会自动存在 `jump_config.json`，下次打开会沿用。

## 检查判断对不对

每一跳都会把标记过的截图存在 `debug\latest.png`（和最近 30 张）：
绿色圈 = 小人脚底，红色圈 = 目标方块中心。

只想测判断、不想真的按：双击 **`测试判断.bat`**。

## 常见问题

- **找不到 adb.exe**：确认 `C:\platform-tools\adb.exe` 存在，或在 `jump_config.json` 的 `"adb"` 写完整路径。
- **没有找到手机 / 还没授权**：换条 USB 线（有些只能充电），手机上重新允许 USB 调试。
- **找不到 ESP32**：确认 ESP32 有电，手机网页已经断开蓝牙；电脑的蓝牙要打开。
- **找不到小人**：看 `debug\latest.png`。如果手机颜色比较不一样，调整 `jump_config.json` 的 `piece_rgb_min` / `piece_rgb_max`。
- **红色圈位置怪怪的**：可能是特效或分数挡到；按 `r` 重新截图，或手动输入 ms。

## 📦 导出数据 + 录屏（让 Claude 帮你重新校准）

1. **开始录屏**（建议录手机画面，看得到真正的落点）：手机下拉快捷选单 →「屏幕录制」。
   也可以同时录电脑画面：Windows 按 **Win + Alt + R**（Xbox Game Bar）。
2. 打开 `画线.bat` 照常玩 **20~30 跳**（你画线、AI 自动玩都可以）。
3. 停止录屏，在视窗右边「🧠 学习」按 **📦 导出数据**，会在 `pc\export\` 产生一个 `servo_export_日期-时间.zip`，资料夹会自动打开。
4. 把 **zip 和录屏影片**一起传给 Claude。

zip 里面有：
- `jumps.csv`：每一跳一行（Excel 可以打开）：谁按的、距离、按压 ms、当时的 k/b、AI 预测、落点偏差
- `events.csv`：每个操作的时间（精确到毫秒），用来跟录屏对时间
- `shots/`：每一跳**按之前**和**跳完之后**的截图
- `log.json`、`jump_config.json`、`summary.txt`：完整资料、设定、统计
